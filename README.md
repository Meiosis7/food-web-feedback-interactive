# 食物网营养结构与负反馈调节

一生儿 · 高中生物一本通｜选择性必修 2

通过草、兔、鼠、食草昆虫、蛙、蛇、鹰组成的简化食物网，逐步分析营养结构和种群间的反馈作用。

## 使用

[打开在线演示](https://meiosis7.github.io/food-web-feedback-interactive/)

下载 `index.html` 后用浏览器打开即可离线使用，图片、样式和脚本均已内嵌，无需安装依赖。

- **食物网**：7 种生物、10 条取食关系、5 条完整食物链，点击生物或食物链查看联系。
- **营养结构**：沿不同食物链比较营养级与消费者级别。
- **影响与负反馈**：任选起始种群和观察种群，设置最初增多或减少，逐步追踪影响，或闭合回路判断正、负反馈。
- 提供捕食、竞争、间隔营养级、跨食物链和相反路径示例；支持逐步演示、自动播放、路径比较和全屏。
- 主图、控制区和分析结果采用紧凑布局；详细说明通过知识卡展开。

## 模型边界

灰箭头表示食物到取食者；彩箭头表示当前路径的作用方向。增减标记是其他途径暂不合并时的条件性影响趋势，不是实际种群数量预测。路径存在相反作用时，不能按路径条数决定整网净变化。

开放路径不重复节点；闭合回路只在末尾重复起点。只有回传作用抑制最初变化时，该回路才属于负反馈；负反馈不保证立即恢复原数量，也不单独保证整个生态系统稳定。

共享资源竞争、共同天敌作用和营养级联均通过中间生物展示。鼠按植食性消费者处理；本图未涵盖真实生态系统的所有取食关系、作用强度与响应时滞。参考文献链接位于知识卡中。

## 修改与验证

源文件和素材位于 `src/`。修改后重新生成入口：

```sh
python3 src/build.py
node --test src/model.test.cjs src/influence.test.cjs
node --check src/app.js
```

15 项测试覆盖食物链、营养级及影响分析；其中新影响分析覆盖全部 42 组不同种群的有序组合。旧的两种群数量模拟函数仅为兼容保留，当前页面不调用它。

2026-10-12 版本已在真实浏览器检查关键交互，以及 1366×768、500×949、390×843 的紧凑排布。

生物插图为 AI 生成，提示词见 `src/ART-PROMPT.md`；草地背景沿用本系列作品。

## 默认先讲最直接的通路

影响分析默认保留最短路线，并补充一条最短的反向作用路线。闭合反馈默认只列起始种群与直接相邻生物的两步往返回路，按“食物制约”“天敌制约”比较；此时无需选择观察种群。点击“展开更多”后才显示完整影响路径，或经过所选种群的拓展闭环。拓展回路不代表主要调节机制，路径最短也不代表作用最强。

食草昆虫默认只有“昆虫→草→昆虫”和“昆虫→蛙→昆虫”两条反馈。新增测试覆盖全部种群的直接回路与 42 组影响分析的最短、反向路径选择；共 15 项测试通过。实际浏览器核对了上述两条回路、初始减少、展开/收起、竞争和相反路径；390×843 视口下正文与分析面板无纵向溢出。
